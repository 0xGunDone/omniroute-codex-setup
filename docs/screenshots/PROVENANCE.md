# Screenshot provenance / Происхождение скриншотов

Real OmniRoute 3.8.52 dashboard captured on 2026-10-27 Moscow, using a separate local Docker Compose project with an empty volume. UI locales: Russian and English. Viewport 1440×1000. No real upstream provider account or router API key was added.

Retained as illustrative screenshots in the 2026-11-11 update. OmniRoute 3.8.53 changes the theme to Keak UI Kit / Editions; colors and button placement may differ. These images are not presented as captures of 3.8.53.

- `*-01-codex-provider.png`: Providers → OpenAI Codex, empty connections and built-in model catalog.
- `*-02-add-account.png`: provider notice displayed after clicking Add. This is an upstream UI notice, not an authentication success screen.
- `*-03-api-manager.png`: API Keys / API Manager before creating a key.

Demo used port 21280 to avoid colliding with a user's gateway. Guide's default port is20128. OAuth sign-in, model entitlement and completed image/search requests are not implied by screenshots. No AI-generated UI or screenshots of a private production installation were used.
